## What Acme is

<Lead>
  Acme is a small, open-source toolkit for building, testing and shipping
  widgets. It gives you one config file, one CLI and a predictable pipeline
  from source to deploy — so you spend your time on the widget, not the
  plumbing around it.
</Lead>

## Why it exists

Most widget projects start the same way: copy an old repo, delete half of it,
and fight the build for an afternoon. Acme replaces that with a single
`acme init` and sensible defaults you can override one key at a time.

## Who it's for

- Developers who want a working project in minutes, not hours.
- Teams that need the same build and deploy steps on every machine.
- Maintainers who want config changes to be reviewable in one file.
